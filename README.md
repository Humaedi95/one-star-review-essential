# One-Star Review of Something Essential

A deadpan one-star review of gravity — the everyday essential that holds the
whole planet together yet cannot be trusted with the small things we actually
care about. One line, filed in earnest, with the sting saved for the end.

> Gravity holds the whole planet together but cannot be trusted with a phone, a plate, or anything you actually liked.

## Run it

```sh
node main.ts
```

This writes the single review line (116 characters, one line) to
`/output/entry.txt`. Set `OUTPUT_DIR` to write it somewhere else.
